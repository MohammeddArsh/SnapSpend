## Reporting a Vulnerability

If you discover a security vulnerability or sensitive secret exposure within this repository:

1. **Do NOT open a public issue** on GitHub.
2. Send a private disclosure email to the maintainer or submit a report via GitHub Security Advisory.
3. Include detailed steps to reproduce the vulnerability.

We aim to acknowledge receipt of reports within 48 hours and work quickly to release patches for confirmed issues.
